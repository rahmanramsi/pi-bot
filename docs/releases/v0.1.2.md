# Pi Bot v0.1.2

Hotfix for the public-alpha macOS package.

## Fixed

- The packaged renderer now loads Vite assets with relative paths, so Pi Bot no longer opens to a blank black window from `file://`.
- Added a release check that rejects root-relative asset paths before packaging.

## Install

Download `PiBot-0.1.2-arm64.dmg`, verify the SHA-256 checksum, and move Pi Bot to Applications.

Pi Bot is not notarized by Apple. If macOS blocks the first launch, open **System Settings → Privacy & Security** and click **Open Anyway** for Pi Bot.

## Known limits

- Apple Silicon macOS only.
- Ad-hoc signed and not notarized.
- No sandbox, per-action approval, automatic updates, or automated test suite.
- Use only a workspace you deliberately selected and can recover.

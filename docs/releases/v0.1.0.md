# Pi Bot v0.1.0

First public alpha for macOS Apple Silicon.

## Included

- Local agent profiles, selected workspaces, instructions, skills trust, and persistent sessions.
- Provider setup, model selection, reasoning levels, streaming responses, and visible tool activity.
- A one-time setup acknowledgement that the agent can run commands and modify files without per-action approval.

## Install

Download `Pi-Bot-0.1.0-arm64.dmg`, verify the SHA-256 checksum, move Pi Bot to Applications, then Control-click and choose **Open** because this alpha is unsigned.

## Known limits

- Apple Silicon macOS only.
- Unsigned and not notarized.
- No sandbox, per-action approval, automatic updates, or automated test suite.
- Use only a workspace you deliberately selected and can recover.

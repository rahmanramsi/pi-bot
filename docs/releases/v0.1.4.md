# Pi Bot v0.1.4

Hotfix for repeated macOS Safe Storage prompts.

## Changed

- Removed Electron Safe Storage and all startup Keychain access.
- Provider credentials now use `credentials.json` in Pi Bot's app-data directory, written with owner-only permissions (`0600`).
- Existing Keychain-stored Pi Bot credentials are intentionally not migrated. Reconnect or import Pi credentials after installing this version.
- Fixed the setup logo path in the packaged app.

## Install

Download `PiBot-0.1.4-arm64.dmg`, verify the SHA-256 checksum, and move Pi Bot to Applications.

## Known limits

- Apple Silicon macOS only.
- Ad-hoc signed and not notarized.
- Credentials are stored locally in a protected app file, not in macOS Keychain.
- No sandbox, per-action approval, or automatic updates.

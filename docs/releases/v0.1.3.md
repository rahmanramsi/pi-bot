# Pi Bot v0.1.3

Reliability update for the public-alpha macOS package.

## Fixed

- Avoided Keychain-backed browser storage during app startup, so first setup can render before a credential is added.
- Kept packaged renderer assets relative to the app bundle, including the app icon path.
- Added a repeatable packaged smoke test that opens the release app and verifies the first setup screen.

## Install

Download `PiBot-0.1.3-arm64.dmg`, verify the SHA-256 checksum, and move Pi Bot to Applications.

Pi Bot is not notarized by Apple. If macOS blocks the first launch, open **System Settings → Privacy & Security** and click **Open Anyway** for Pi Bot.

## Known limits

- Apple Silicon macOS only.
- Ad-hoc signed and not notarized.
- No sandbox, per-action approval, or automatic updates.
- Connecting a provider will ask macOS to allow access to Pi Bot Safe Storage; enter the Mac login keychain password and choose **Allow** or **Always Allow**.
- Use only a workspace you deliberately selected and can recover.

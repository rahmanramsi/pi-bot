# Pi Bot v0.1.1

Public-alpha packaging fix for macOS Apple Silicon.

## Fixed

- The app bundle is now ad-hoc signed consistently, so macOS no longer reports it as damaged.
- Build output is separated from the Vite frontend output, preventing old DMGs from being embedded in a new app.
- Renderer-only packages, including Mermaid, are bundled by Vite instead of being copied as runtime dependencies.

## Install

Download `PiBot-0.1.1-arm64.dmg`, verify the SHA-256 checksum, and move Pi Bot to Applications.

Pi Bot is not notarized by Apple. If macOS blocks the first launch, open **System Settings → Privacy & Security** and click **Open Anyway** for Pi Bot.

## Known limits

- Apple Silicon macOS only.
- Ad-hoc signed and not notarized.
- No sandbox, per-action approval, automatic updates, or automated test suite.
- Use only a workspace you deliberately selected and can recover.
